# P8 阶段任务边界

## 冻结目标

P8 交付匿名候选、版本化评测集、Mock/DashScope 回放、确定性评分、版本对比、签名门禁和最小评测控制台。P8 只签发门禁证明，不自动发布、灰度或回滚。

## 并行任务

| 任务 | 独占目录 | 禁止修改 |
|---|---|---|
| P8-A | `evaluation/{intake,anonymization,candidate,dataset}` 及对应测试 | B/C 目录、公共契约、Flyway、POM、YAML、Gateway、P5、knowledge、frontend |
| P8-B | `evaluation/{replay,runner,scoring,judge,comparison}` 及对应测试 | A/C 目录、公共契约、Flyway、POM、YAML、Gateway、P5、knowledge、frontend |
| P8-C | `evaluation/gate`、`frontend/apps/aliagent-admin/src/evaluation`、`evaluation-client.ts` 及明确列出的前端入口文件 | A/B 目录、公共契约、Flyway、POM、YAML、Gateway、P5、knowledge |

三个任务从同一冻结提交创建，不得互相合并。跨任务依赖通过本任务自有端口表达，集成会话实现适配器。

## 集成会话专属修改

- `contracts/` 中 P8 OpenAPI、AsyncAPI 和 Schema。
- `evaluation-service` 的 Flyway、配置、POM、应用装配和现有占位控制器替换。
- P5 Prompt/工作流/模型发布与灰度门禁。
- knowledge 不可变快照和发布门禁。
- Gateway、Compose、CI、公共部署配置和完整 E2E。

## 数据与安全

- 原始事件 payload 不得持久化到 Inbox、日志或异常信息。
- 候选持久化前必须匿名化；失败样本进入隔离且正文不可见。
- 租户样本默认私有；公共共享必须二次匿名化和租户管理员显式授权。
- 所有租户事实使用可信请求上下文，不接受客户端 tenantId 作为授权依据。
- Gate Decision 绑定租户、目标版本、清单摘要、策略和有效期，伪造或不匹配默认拒绝。
- 测试资源使用 `test-` 或 `rag-test-` 前缀并在验收后清理。

## 合并门禁

每个任务必须提供提交 SHA、变更文件、测试命令和结果、剩余公共接口缺口。集成会话按 A、B、C 顺序合并，完成契约、迁移、装配、版本治理连接和全链路验收后才允许进入主线 PR。
